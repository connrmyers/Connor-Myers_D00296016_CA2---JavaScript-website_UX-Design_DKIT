UX Web Design

Pipshots — Website Build

A conversion-focused portfolio website designed and built to increase client enquiries and simplify the booking journey for a local photographer.

Responsive Performance Bootstrap Ease of contact Branding
Visit website Get in touch

Preview: homepage → portfolio → contact

The brief

The project focused on reducing friction through fast load times, clear navigation, and prominent contact pathways, resulting in more consistent and higher-quality enquiries. Designed and built from scratch using HTML, CSS and JavaScript to maximise performance, accessibility and UX control. The client reported an increase in direct enquiries and improved booking clarity following launch.

Key requirements
  • Responsive across devices
  • Quick load time and lightweight pages
  • Simple navigation + clear portfolio browsing
  • Obvious contact options for enquiries
Brand direction
  • Bold “witchy tattoo” personality — cinematic feel
  • Dark leaning palette, warm highlights
  • Expressive but readable typography
  • Photography stays the hero
